# Estudos de HTML & CSS (Curso em Vídeo)

Repositório com meus estudos e exercícios de **HTML5 e CSS3**, seguindo as aulas e desafios do **Curso em Vídeo**.  
Aqui eu organizo práticas, páginas e mini projetos para evoluir em estrutura, layout, responsividade e boas práticas.

## 🎯 Objetivos
- Praticar **HTML semântico**
- Evoluir em **CSS (layouts, responsividade, organização)**
- Construir mini projetos para portfólio
- Criar uma base sólida para avançar para **JavaScript/React**

## 📌 Conteúdo (o que você encontra aqui)
- Exercícios por aula/módulo
- Desafios práticos (layouts completos)
- Mini projetos com foco em:
  - Responsividade
  - Tipografia
  - Flexbox / Grid
  - Estrutura de páginas
  - Organização de arquivos

## 📁 Organização do repositório
> Ajuste os nomes abaixo conforme suas pastas reais.
- `exercicios/` — práticas e exercícios
- `desafios/` — desafios propostos no curso
- `projetos/` — mini projetos completos

## ▶️ Como rodar
1. Abra qualquer arquivo `.html` no navegador  
ou  
2. Use o **Live Server** no VS Code (recomendado):
   - Instale a extensão *Live Server*
   - Clique com o botão direito no arquivo HTML → **Open with Live Server**
